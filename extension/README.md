# Triloa Edge 网页视口翻译扩展

此 Edge Manifest V3 扩展可在你选定的网站识别当前视口可见的英文和日文段落，在悬浮窗中显示中文。滚动、窗口尺寸变化或页面动态载入内容后会重新扫描。

## 安装

1. 确认 Triloa 本地翻译服务已经启动，监听 `127.0.0.1:8765`，并允许 `chrome-extension://` / `edge-extension://` 来源。
2. 在 Edge 打开 `edge://extensions` 并启用“开发人员模式”。
3. 选择“加载解压缩的扩展”，指向源码根目录下的 `extension` 文件夹。
4. 刷新已经打开的网页。

## 使用

- 每个网站默认关闭。打开普通网页后，左键点击 Edge 工具栏中的 Triloa 图标，在弹窗中打开“在此网站启用翻译”。设置保存在扩展本地存储中，同一网站的不同页面共用开关；不同协议、域名或端口分别设置。关闭后立即移除翻译窗并停止扫描，重新开启后恢复。
- 开启后，拖动翻译窗标题栏可移动位置；拖动右下角可调整大小。点击“固定”后锁定位置和大小，点击“已固定”可解锁。位置、大小和固定状态按网站保存；窗口尺寸变化时会保持在可见区域内。
- 右上角“×”仅收起翻译窗，扫描仍继续；点击“显示翻译”可重新展开。要停止该网站的翻译，请使用工具栏弹窗中的开关。
- Edge 自带的“网站访问权限”菜单与 Triloa 弹窗中的逐网站开关是两层设置。若 Edge 禁止此扩展访问该网站，开启 Triloa 开关后仍需在 Edge 中允许访问并刷新网页。
- 修改扩展文件后，在 `edge://extensions` 点击该扩展的“重新加载”，再刷新已打开的网页。若加载的是文件夹版，请更新 `dist/Triloa/extension` 中的文件。

## 本地接口

扩展后台 service worker 将一批段落发送到固定地址 `http://127.0.0.1:8765/translate`：

```json
{"texts":["English or Japanese paragraph"],"source":"auto","target":"zh"}
```

服务需返回相同数量、按输入顺序对应的翻译：

```json
{"translations":["中文翻译"],"model_id":"当前模型的不透明标识"}
```

无法连接服务、服务返回错误、模型不可用或响应格式错误时，面板会显示可见错误信息，不会将失败标成成功。请求超时为 90 秒；失败段落至少等待 8 秒才会尝试重试。

开启的网站每 2 秒通过 `/health` 检查 `model_id`。切换 HY-MT／Qwen 或重启本地服务后，清除旧模型缓存并重新翻译可见段落；旧请求的迟到结果不会覆盖新模型译文。检查模型本身不加载模型。公开首版扩展 0.1.1 配套使用 Triloa v0.1 服务。

## 网络和数据

翻译请求只从扩展后台发往固定的 `127.0.0.1:8765` 地址。页面脚本只通过扩展 runtime messaging 传递待翻译文本，不会直接连接网络。扩展不包含云端接口、第三方库、统计或遥测，也不发送网页 URL。翻译缓存只保存在当前标签页内存中，最多保留 500 段。

扩展的逐网站开关及翻译窗位置、大小、固定状态保存在 Edge 扩展的本地存储中。未开启的网站不会扫描段落或请求翻译。扩展需要 Edge 的网页访问权限才能在开启的网站读取当前视口段落；Edge 的权限菜单可能仍显示扩展拥有网站访问权限，但 Triloa 的逐网站开关默认关闭。
