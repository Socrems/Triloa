# Triloa Edge 网页双语翻译扩展

此 Edge Manifest V3 扩展在选定网站的英文和日文正文段落、常见标题（h1–h6）和列表项下方显示中文译文，保留原文、链接与格式。滚动到新内容或页面动态更新后，会继续翻译。

## 安装

1. 确认 Triloa 本地翻译服务已经启动，监听 `127.0.0.1:8765`，并允许 `chrome-extension://` / `edge-extension://` 来源。
2. 在 Edge 打开 `edge://extensions` 并启用“开发人员模式”。
3. 选择“加载解压缩的扩展”，指向本目录中的 `extension` 文件夹。
4. 刷新已经打开的网页。

## 使用

- 每个网站默认关闭。点击 Triloa 扩展图标，开启“在此网站启用翻译”。同一协议、域名和端口共用开关。关闭后移除扩展插入的译文并停止扫描。
- 译文按可见区域逐批加载，每批最多 32 项。相同原文共用翻译，分别显示在各自下面。嵌套列表不会重复翻译子列表。
- 不处理导航、编辑框、代码块、表格单元格、浏览器 PDF 或跨域 iframe；复杂网页可使用屏幕 OCR。旧版翻译窗位置不再使用。
- Edge 自带的“网站访问权限”菜单与 Triloa 弹窗中的逐网站开关是两层设置。若 Edge 禁止此扩展访问该网站，开启 Triloa 开关后仍需在 Edge 中允许访问并刷新网页。
- 修改扩展文件后，在 `edge://extensions` 点击该扩展的“重新加载”，再刷新已打开的网页。若加载的是文件夹版，请更新 `dist/Triloa/extension` 中的文件。

## 本地接口

扩展后台 service worker 将一批段落发送到固定地址 `http://127.0.0.1:8765/translate`：

```json
{"texts":["English or Japanese paragraph"],"source":"auto","target":"zh"}
```

服务需返回相同数量、按输入顺序对应的翻译：

```json
{"translations":["中文翻译"],"model_id":"当前模型的不透明标识"}
```

无法连接服务、模型不可用或响应格式错误时，页面右下角显示错误及“重试”按钮。请求超时为 90 秒；失败段落自动重试至少间隔 8 秒，也可手动重试。

开启的网站每 2 秒通过 `/health` 检查 `model_id`。切换模型或重启服务后，移除旧译文并重新翻译可见文字；旧请求的迟到结果不会覆盖新模型译文。检查本身不加载模型。建议搭配 v0.1.3 桌面程序使用。

## 网络和数据

翻译请求只从扩展后台发往固定的 `127.0.0.1:8765` 地址。页面脚本只通过扩展 runtime messaging 传递待翻译文本，不会直接连接网络。扩展不包含云端接口、第三方库、统计或遥测，也不发送网页 URL。翻译缓存只保存在当前标签页内存中，最多保留 500 段。

逐网站开关保存在 Edge 扩展本地存储。未开启的网站不会扫描或请求翻译。当前标签页最多保留 500 项译文和对应节点；关闭开关后全部清除。Edge 的访问权限与 Triloa 的网站开关分别设置。
