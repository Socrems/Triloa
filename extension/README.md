# Triloa Edge 网页双语翻译扩展

此 Edge Manifest V3 扩展在选定网站的英文和日文正文段落、常见标题（h1–h6）和列表项下方显示中文译文，保留原文、链接与格式。滚动到新内容或页面动态更新后，会继续翻译。

## 安装

1. 确认 Triloa 本地翻译服务已经启动，监听 `127.0.0.1:8765`，并允许 `chrome-extension://` / `edge-extension://` 来源。
2. 在 Edge 打开 `edge://extensions` 并启用“开发人员模式”。
3. 选择“加载解压缩的扩展”，指向本目录中的 `extension` 文件夹。
4. 普通已打开的网页会尝试自动加载；从 v0.1.3 升级后，请刷新旧网页完成升级。浏览器内置页面、扩展商店和浏览器 PDF 等受限页面无法保证注入。

## 使用

- 每个网站默认关闭。点击 Triloa 扩展图标，开启“在此网站启用翻译”。同一协议、域名和端口共用开关。关闭后移除扩展插入的译文并停止扫描。
- “显示网页悬浮球”默认关闭，是独立的全局显示设置。开启后，普通网页侧边显示 44 像素悬浮球；点击可切换本站翻译或原文。悬浮球显示但本站翻译关闭时，不扫描正文或请求本地模型。
- 悬停或用 Tab 聚焦悬浮球可展开“设置”和“隐藏”。隐藏只作用于本站，可从扩展弹窗点击“恢复本站悬浮球”；隐藏或全局关闭悬浮球都不会关闭本站翻译。设置面板可关闭全局显示或恢复默认位置，Esc 收起面板。按钮支持 Enter 和空格。
- 拖动悬浮球后松手会吸附窗口左右边缘，并保存高度比例；所有网页共用位置。拖动过程中不写存储，松手后的点击不会误切换翻译。缩放窗口后位置会保持在可见区域内。
- 译文按可见区域逐批加载，每批最多 32 项。相同原文共用翻译，分别显示在各自下面。嵌套列表不会重复翻译子列表。
- 不处理导航、编辑框、代码块、浏览器 PDF 或 iframe；扩展只注入网页顶层。复杂网页可使用屏幕 OCR，旧版翻译窗位置不再使用。
- Edge 自带的“网站访问权限”菜单与 Triloa 弹窗中的逐网站开关是两层设置。若 Edge 禁止此扩展访问该网站，开启 Triloa 开关后仍需在 Edge 中允许访问并刷新网页。
- 修改扩展文件后，在 `edge://extensions` 点击该扩展的“重新加载”。v0.1.4 支持重复注入时卸载旧控制器；v0.1.3 没有卸载接口，旧页面检测到残留脚本或译文时会提示刷新，无法声称已清除其全部监听。若加载的是文件夹版，请更新 `dist/Triloa/extension` 中的文件。

## 本地接口

扩展后台 service worker 将一批段落发送到固定地址 `http://127.0.0.1:8765/translate`：

```json
{"texts":["English or Japanese paragraph"],"source":"auto","target":"zh"}
```

服务需返回相同数量、按输入顺序对应的翻译：

```json
{"translations":["中文翻译"],"model_id":"当前模型的不透明标识"}
```

无法连接服务、模型不可用或响应格式错误时，页面右下角显示错误及“重试”按钮。请求超时为 90 秒；失败段落自动重试至少间隔 8 秒，也可手动重试。

开启的网站每 2 秒通过 `/health` 检查 `model_id`。切换模型或重启服务后，移除旧译文并重新翻译可见文字；旧请求的迟到结果不会覆盖新模型译文。检查本身不加载模型。建议搭配 v0.1.4 桌面程序使用。

## 网络和数据

翻译请求只从扩展后台发往固定的 `127.0.0.1:8765` 地址。页面脚本只通过扩展 runtime messaging 传递待翻译文本，不会直接连接网络。扩展不包含云端接口、第三方库、统计或遥测，也不发送网页 URL。翻译缓存只保存在当前标签页内存中，最多保留 500 段。

逐网站开关保存在 Edge 扩展本地存储。未开启的网站不会扫描或请求翻译。当前标签页最多保留 500 项译文和对应节点；关闭开关后全部清除。Edge 的访问权限与 Triloa 的网站开关分别设置。

v0.1.4 使用 `scripting` 和普通 HTTP(S) 网站访问权限，在扩展安装/更新或悬浮球从关闭变为开启时，尝试给已打开的普通网页顶层注入脚本。单页注入失败不会影响其他标签页；不请求 `tabs`、文件 URL 或所有框架权限。无需启用文件 URL 访问。网页文字仍只在本站翻译开启后发送给固定的本地服务。

存储键：`triloa:enabled:<origin>`（本站翻译，默认 false）、`triloa:ball:enabled`（全局显示，默认 false）、`triloa:ball:hidden:<origin>`（本站隐藏，默认 false）、`triloa:ball:position`（`{side:"right",yRatio:0.5}`）。初始读取不会覆盖较新的变更；保存失败会回滚当前操作并显示提示。
