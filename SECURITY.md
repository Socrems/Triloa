# Security Policy / 安全政策

## Release scope / 版本范围

As of **2026-10-16**, **v0.1.4 has been published**. Security review focuses on the latest published release on a best-effort basis. There is no commitment to backport fixes to older releases. See [Releases](https://github.com/Socrems/Triloa/releases) for published versions.

截至 **2026-10-16**，**v0.1.4 已正式发布**。安全问题的审查尽力聚焦最新公开版本，不承诺向旧版本回移修复。公开版本见 [Releases](https://github.com/Socrems/Triloa/releases)。

## Reporting a vulnerability / 报告漏洞

**Private vulnerability reporting is disabled as of 2026-10-16.** This document does not mean a working private reporting channel is available. Check the repository's [security policy page](https://github.com/Socrems/Triloa/security/policy) for the current reporting options.

**截至 2026-10-16，私密漏洞报告功能处于关闭状态。** 本文不表示已经存在可用的私密报告渠道。请查看仓库的[安全政策页面](https://github.com/Socrems/Triloa/security/policy)，确认当前可用的报告方式。

If private reporting is unavailable, you may open a general issue asking maintainers to enable it. Include only the request to enable a private channel. Do not include vulnerability details, affected endpoints, reproduction steps, exploit code, logs, or sensitive data in public issues, pull requests, or comments. Wait until a private channel is available before sharing those details. No separate project security email or private reporting channel is currently listed here.

如果私密报告不可用，可新建普通议题，请维护者启用私密渠道；议题中只提出启用请求。不要在公开议题、拉取请求或评论中发布漏洞细节、受影响的接口、复现步骤、利用代码、日志或敏感数据。请等到私密渠道可用后再提供这些信息。本文目前未列出其他项目安全邮箱或私密报告渠道。

**For maintainers:** enable **Settings → Advanced Security → Private vulnerability reporting** in the GitHub repository. Once enabled, reporters can use [Report a vulnerability](https://github.com/Socrems/Triloa/security/advisories/new). That link is conditional on the feature being enabled; it is not currently an available reporting promise.

**维护者操作：**在 GitHub 仓库的 **Settings → Advanced Security → Private vulnerability reporting** 中启用功能。启用后，报告者可使用[报告漏洞](https://github.com/Socrems/Triloa/security/advisories/new)入口；该链接以功能已开启为前提，不代表当前承诺提供此渠道。

When a private channel is available, provide the version, potential impact, minimal reproduction steps, and any workaround, with personal data removed. We cannot promise a response deadline, fix or maintenance timeline, or bounty. Please coordinate disclosure with maintainers through the available private channel.

私密渠道可用后，请提供版本、潜在影响、最小复现步骤及已知临时措施，并移除个人数据。本项目不承诺回应期限、修复或维护时间表，也不承诺漏洞奖励。请通过可用的私密渠道与维护者协调披露。
