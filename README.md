# Triloa

Windows 本地翻译工具：文字与剪贴板翻译、屏幕 OCR、网页翻译、系统声音双语字幕。

**当前版本：v0.1.4，本地审核中。** 项目自有源码采用 [MIT](LICENSE) 许可证。

## 下载并开始使用

1. 本地审核使用 **`Triloa-v0.1.4-windows-x64.zip`**；完整解压后使用。公开版本和附件请查看 [Releases](https://github.com/Socrems/Triloa/releases)，v0.1.4 尚未发布。`source.zip` 是与 main 对应的源码安装包。
2. **完整解压**到可写文件夹，例如 `D:\Apps\Triloa`，双击 **`Triloa.exe`**。保留旁边的 `_internal` 等目录。
3. 首次打开时，选择需要的功能并点击“开始安装”：

   | 用途 | 自动准备的资源 | 下载量约 |
   |---|---|---|
   | 基础翻译 | 英语→中文、日语→英语、断句和屏幕 OCR | 211 MB |
   | 实时字幕 | 基础翻译，再加多语言 Whisper base 和语音检测 | 共 353 MB |
   | Qwen3-ASR 字幕（可选） | 基础翻译，再加 Qwen3-ASR-0.6B 完整模型目录 | 共约 2.10 GB |

4. 安装完成后开始使用。已有资源会直接复用，下载显示进度、大小和当前步骤；失败后点击“重试安装”。也可稍后从首页的 **“资源管理”** 补装。

便携包包含 Python 和必要依赖，**无需安装 Python 或完整 CUDA Toolkit**，基础功能使用 CPU。包内不含模型；第一次安装资源需要联网，之后这些功能可以离线运行。部分网络可能无法连接模型托管网站，失败原因会显示在安装窗口。

目前支持 Windows 11 x64，其他系统尚未验证。基础用途建议预留至少 3 GB，选择 Qwen3-ASR 建议预留至少 5 GB；程序文件夹可以放在 D 盘。此版本尚未签名，Windows 可能显示安全提示，请核对下载来源。

## 日常使用

- **文字翻译**：输入英文或日文，按 `Ctrl+Enter`；也可点击“翻译剪贴板”。日语的基础翻译通过英语转译为中文。
- **屏幕翻译**：点击“框选翻译”，或在“屏幕翻译”页选择持续监视区域。
- **实时字幕**：打开字幕页，选择 `faster-whisper base` 或安装好的 `Qwen3-ASR-0.6B`、识别语言和播放设备，点击“开始字幕”。字幕读取电脑播放的声音。
- **Qwen3-ASR**：在资源管理勾选该模型下载，完成后自动填写模型目录；已有模型时在字幕页先选 Qwen3-ASR，再在“模型目录”点击“选择文件夹”。它负责识别，译文仍由首页选定的翻译模型生成。普通便携包使用 CPU；源码版可按安装说明配置 NVIDIA 显卡加速。
- **网页翻译**：在 `edge://extensions` 开启开发人员模式并加载包内 `extension`，在扩展中开启当前网站。中文译文会显示在正文、标题和列表项下面。可在扩展设置中开启全局悬浮球：单击切换当前网站的翻译与原文，悬停或用键盘聚焦后展开设置与本站隐藏操作；拖动后吸附左右边缘，并记住跨网站共用的高度。隐藏球会保留译文。桌面程序保持运行。见 [扩展说明](extension/README.md)。

翻译模型共用首页的选择列表。可添加自己下载的 GGUF 文件，选择对应的模型提示配置；便携包附带 CPU llama.cpp 运行库。需要显卡加速或其他语音模型时，见 [模型与源码安装说明](docs/SOURCE_INSTALL.md)。

“管理模型”菜单集中提供添加、编辑和移除操作。字幕启动后会显示识别使用的 CPU / CUDA，整句模式等待停顿后显示，实时模式会先更新草稿。

主窗口、设置、模型与资源窗口采用统一的浅色圆角界面，顶部模型操作分为两行，字幕设置更紧凑。字幕历史保留深色半透明样式。

下拉选择框收起时，滚轮不会改变选项；点击展开后可以滚动列表，再点击选择。

## 更新与本地数据

新版本建议解压到新文件夹，关闭旧程序后再启动。保留资源和设置可复制旧目录的 `data`、`models`；正在下载的进度位于 `downloads`。自选 GGUF 和外部 Qwen3-ASR 目录只记录路径，移动后请重新选择。更新后在扩展管理页重新加载扩展；普通 HTTP(S) 页面支持补充注入，浏览器内部页面等受限页面不支持。已打开的 v0.1.3 页面若保留旧脚本或出现重复译文，请刷新网页。

便携包默认把模型、缓存、设置和日志放在解压目录内。字幕历史和译文缓存只保留在会话内存中。网页扩展把可见段落发送到本机 `127.0.0.1:8765`，本地服务仅监听回环地址。系统和浏览器仍可能产生自身缓存。

这是早期版本：OCR、语音识别和翻译可能有误差，字幕速度取决于硬件和模型；尚未完成全新电脑及所有播放器的兼容性验证。
